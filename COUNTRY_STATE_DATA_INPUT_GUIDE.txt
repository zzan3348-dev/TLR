TLR 국가 현재 상태 데이터 입력 안내서
====================================

목적
----
이 문서는 국가별 설정을 실제 사이트에 입력할 때 필요한 현재 상태 수치와 텍스트를 정리한 입력용 기준이다.
현재 일부 화면은 플레이스홀더 값(0, 빈 배열, 미설정)으로 동작하므로, 국가 데이터를 작성할 때 아래 항목을 채운다.
국가마다 단위를 통일하고, 수치가 없는 항목은 임의로 추정하지 말고 비워 둔다.

1. 국가 기본 식별 정보
----------------------
- countryKey: 사이트 내부 국가 키. 반드시 고유해야 한다.
- id / key: 지도 국가 인덱스와 연결되는 식별자.
- name: 한국어 정식 국명.
- nativeName 또는 englishName: 현지어·영문 정식 국명.
- mapLabel / shortLabel: 지도 위에 표시할 이름. 긴 국명은 지도용 짧은 이름을 별도로 둔다.
- color: 지도 대표색 HEX.
- flagPath: 국기 PNG/WebP 경로. 파일이 없으면 임의 이미지를 넣지 않는다.
- capital: 수도.
- status: 국가의 현재 지위(예: 독립국, 자치령, 식민지 등).
- factionMembership: factionId와 status(member/observer). 가입하지 않은 국가는 null.

2. 국가 공개 정보·패널
----------------------
- leader.name: 현재 지도자 이름. 인물 데이터가 확정되지 않았으면 비워 둔다.
- leader.title: 직위 또는 칭호.
- leader.portraitPath: 지도자 초상화 경로. 없는 경우 빈 값.
- politics.government: 정부·통치기구의 명칭.
- politics.ideology: 집권 사상.
- politics.rulingParty: 집권 정당 또는 집권 세력.
- politics.faction: 소속 세력 표시명.
- politics.symbolPath: 정당·사상 아이콘 경로.
- politics.parties: 정당 목록.
  - id, name, ideology, support(지지도 %), color, symbolPath
- nationalSpirits: 국민정신 목록.
  - id, name, description, imagePath, effects(효과명과 수치)
- description: 국가 개요 또는 현재 상황 설명.
- motto: 국가 표어.
- gallery: 국가 설명판에 표시할 이미지 경로 목록.
- details: 추가 공개 정보(지역, 인구 설명 등).

3. 상단 전략 상태 수치
-----------------------
현재 플레이 화면의 공통 상태는 다음 값을 사용한다.

- politicalPower: 현재 정치력.
- politicalPowerChange: 일일 정치력 변동량.
- stability: 안정도(%).
- warSupport: 전쟁 지지도(%).
- manpower: 가용 인력.
- productionCapacity.total: 총 생산력.
- productionCapacity.used: 사용 중인 생산력.
- productionCapacity.fromDomesticEconomy: 국내 경제에서 오는 생산력.
- productionCapacity.fromTrade: 무역으로 확보한 생산력.
- productionCapacity.other: 기타 생산력.

수치 규칙:
- 퍼센트는 숫자만 입력하고 화면에서 %를 붙인다(예: 42.5).
- 일일 변화량은 양수·음수를 명시한다(예: -0.15, +0.20).
- 인력은 게임 내부 단위에 맞춰 정수 또는 소수로 통일한다.

4. 경제 현재 상태
-----------------
현재 Economy 화면에서 직접 연결되는 기본 필드:

- gdp: 명목 GDP.
- nominalGrowth: 명목 성장률(%).
- realGrowth: 실질 성장률(%).
- inflation: 물가상승률(%).
- debt: 정부 부채.
- debtToGdp: GDP 대비 부채 비율(%).
- povertyRate: 빈곤율(%).
- povertyChange: 빈곤율 변화(%p 또는 해당 시스템에서 정한 단위).
- unemploymentRate: 실업률(%).
- graphs.gdp: GDP 시계열 배열.
- graphs.inflation: 물가상승률 시계열 배열.
- graphs.debtRatio: 부채비율 시계열 배열.
- graphs.poverty: 빈곤율 시계열 배열.

경제 화면을 완성하려면 현재 하드코딩·플레이스홀더인 아래 값도 국가별로 추가한다.

- taxRevenue: 세입.
- taxSpending: 세출.
- socialSpending: 사회 지출.
- crisisSignal: 경제 위기 여부와 단계.
- budget: 행정, 국방, 산업, 복지, 교육별 예산 비율(%).
- population: 총인구.
- workingAgePopulation: 생산가능인구.
- gdpPerCapita: 1인당 GDP.
- socialChange: 사회 지표의 현재 변화량.
- recentChanges: 최근 경제·사회 변화 로그.
- resources: 철강, 석유 등 자원별 생산·수입·수출·가격·재고·소비량.
- tradePartners: 교역 상대국, 거래 품목, 거래량, 무역수지.
- automaticTrade: 자동 무역 조정의 기본값(true/false).

5. 법률 데이터
--------------
법률 상태는 countryId와 laws 맵으로 저장한다.
각 laws 항목은 법률 정의의 선택지 id를 넣거나 아직 미설정이면 "unset"을 넣는다.
실제 법률 선택지는 lawDefinitions.ts의 옵션 id를 사용하며 임의의 이름을 만들지 않는다.

정치 법률:
- party-system: 정당 제도
- religion-policy: 종교 정책
- trade-unions: 노동조합
- immigration: 이민 정책
- forced-labor: 강제노동
- assembly: 집회·결사의 자유
- press: 언론의 자유
- franchise: 선거권

군사 법률:
- service: 군 복무 제도
- training: 군사 훈련
- officers: 장교 제도
- exemptions: 병역 면제

경제 법률:
- trade: 무역법
- income-tax: 소득세법
- minimum-wage: 최저임금법
- working-hours: 법정 노동시간
- unemployment: 실업급여
- pensions: 연금
- industry-ownership: 산업 소유 구조
- land-system: 토지 제도

사회 법률:
- healthcare: 의료보험
- education: 교육 정책
- penal-system: 형벌 제도
- policing: 치안 정책
- industry-regulation: 산업 규제
- womens-rights: 여성 권리
- ethnic-policy: 민족 정책
- censorship: 검열

각 법률 선택지에 작성할 값:
- id, 표시명, 설명.
- modifiers: 효과 key, value, unit(flat 또는 percent).
- requirements: 선택에 필요한 조건 key와 label.
- incompatibilities: 동시에 선택할 수 없는 옵션 id 목록.

6. 발전도·사회 기반
--------------------
국가 발전 상태는 countryId, povertyRate, povertyChange, items 배열로 입력한다.
각 item에는 id, level, trend(up/stable/down)를 넣는다.

현재 정의된 발전 항목:
- academic-foundation: 학문적 기반
- research-facilities: 연구 시설
- agriculture: 농업 방식
- health: 보건 수준
- administration: 행정 효율
- industry-specialization: 산업 전문성
- industrial-equipment: 공업 장비
- military-professionalism: 군 전문성

각 발전 항목은 정의 파일에 있는 level 번호와 이름을 사용한다.
level별 효과는 modifiers로 기록하고, 추세가 없으면 stable로 둔다.

7. 외교·대외 관계
-----------------
국가 간 외교 정보는 상대국별로 별도 기록한다.

- targetCountryKey: 상대국 키.
- relation: 현재 관계도.
- relationChange: 일일 관계 변화.
- tradeAccess: 교역 가능 여부와 무역 규모.
- treaties: 체결 조약 목록과 만료일.
- factionRelation: 같은 세력인지, 회원인지, 옵저버인지.
- intelligence: 정보 수준 또는 첩보 상태.
- actionAvailability: 외교 행동별 사용 가능 여부.
- actionCost: 정치력·자원·시간 비용.
- actionRequirements: 행동 조건.

현재 외교창의 행동 목록은 메시지, 관계 개선, 교역 제안, 조약, 정보망 구축 등 UI 셸 중심이므로,
국가별 데이터를 넣을 때 행동의 상태·비용·조건을 함께 정의한다.

8. 수치·효과 작성 규칙
----------------------
- Modifier key는 기존 시스템에서 사용하는 영문 키를 재사용한다.
- unit은 flat(절대값) 또는 percent(백분율) 중 하나로 명시한다.
- 증가 효과는 양수, 감소 효과는 음수로 입력한다.
- 퍼센트와 퍼센트포인트를 혼용하지 말고 해당 필드의 단위를 문서에 명시한다.
- 시계열 배열은 최신 값이 어디에 오는지 모든 국가에서 동일하게 유지한다.
- 데이터가 확정되지 않은 경우 임의의 0을 실제 값으로 취급하지 말고 null, 빈 배열 또는 unset을 사용한다.
- 국기·초상화·아이콘 파일이 없으면 가짜 이미지를 만들지 않는다.

10. 현재 구현과 입력 우선순위
-----------------------------
1) 먼저 countryKey, 국명, 국기, 정부·이념·집권세력을 입력한다.
2) 그 다음 politicalPower, stability, warSupport, manpower를 입력한다.
3) GDP·성장률·물가·부채·빈곤·실업과 그래프 배열을 입력한다.
4) 모든 법률의 현재 옵션 id를 입력한다.
5) 발전도 8개 항목의 level과 trend를 입력한다.
6) 예산·자원·무역·외교의 세부 수치를 입력한다.
7) 국민정신·정당·공개 설명을 검수한다.

현재 화면에 보이는 0, N/A, 빈 그래프, 미설정 문구는 실제 국가 상태가 아니다.
국가 데이터가 완성되면 해당 플레이스홀더를 국가별 값으로 교체해야 한다.
