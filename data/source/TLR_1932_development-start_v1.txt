TLR 1932 전세계 사회발전 8개 항목 시작값
================================================================

기준
- developmentDefinitions.ts의 현재 8개 항목과 1~5단계만 사용.
- 1932년 TLR 세계관 기준의 '현재 실제 역량'을 나타냄.
- 법률의 선진성 자체와 동일하지 않음. 제도가 좋아도 실제 행정·보건·교육 기반이 낮으면 발전 단계는 낮게 배정.
- 5단계는 매우 높은 단계이므로 제한적으로만 사용.
- 유럽 19개국은 기존 작성본의 사회발전 값을 유지.
- 빈곤율/빈곤율 변화는 경제 데이터에 이미 존재하므로 여기서는 8개 단계형 항목만 수록.

[단계 정의]
학문적 기반: 1 교육 기반 미비 / 2 초등교육 보급 / 3 중등교육 확장 / 4 고등교육 체계 / 5 대중 고등교육
연구 시설: 1 개인 연구실 / 2 기초 연구기관 / 3 고급 연구 시설 / 4 국가 연구망 / 5 첨단 연구단지
농업 방식: 1 생계형 농업 / 2 전통 집약농업 / 3 대규모 기계화 / 4 과학적 농업 / 5 고도 자동화
보건 수준: 1 지역 구휼 / 2 기초 보건망 / 3 발전된 보건 / 4 전국 의료망 / 5 예방의학 체계
행정 효율: 1 파편화된 행정 / 2 기초 관료제 / 3 간결한 국가기구 / 4 전문화된 행정 / 5 통합 행정망
산업 전문성: 1 가내 수공업 / 2 초기 공장제 / 3 효율적인 산업 방식 / 4 전문화된 산업 / 5 고도 분업 체계
공업 장비: 1 수공업 중심 / 2 초기 산업 장비 / 3 표준 산업 장비 / 4 현대 공업 장비 / 5 첨단 산업 장비
군 전문성: 1 비정규 병력 / 2 기초 상비군 / 3 전문직업군 / 4 통합 전문군 / 5 고도 전문군
