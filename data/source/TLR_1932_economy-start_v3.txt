TLR 1932 국가 경제 데이터 — 현실·설정·밸런스 재검수 반영본 v3
================================================================

기준연도
- 1932년
- 통화: 미화(USD)
- BUSD = 10억 달러, MUSD = 100만 달러

산정 원칙
- 현실 1929~1933년의 인구·산업화·재정·무역·자원·생산구조를 기본 체급의 기준점으로 사용함.
- TLR에는 현실의 대공황과 동일한 세계적 충격이 존재하지 않으므로, 1932년 현실의 일시적 불황 수치를 그대로 복사하지 않음.
- 현실 자료 → TLR 국경·역사·정치상황 보정 → 국가별 사회발전·자원·기본세팅 교차검수 → 게임 밸런스 순으로 시작값을 확정함.
- 영토가 넓거나 인구가 많다는 이유만으로 GDP·생산능력·연구역량을 자동으로 높이지 않음.
- 실제 산업화, 도시화, 문해율, 행정능력, 산업 전문성, 공업 장비, 자원 접근성과 국가 설정을 함께 봄.
- 강대국도 구조적 문제·전쟁부담·식민지 문제·행정분열이 있으면 낮은 재정건전성 또는 낮은 효율을 가질 수 있음.
- 약소국도 금융·무역·농축산·광물 같은 명확한 강점이 있으면 1인당 지표나 특정 생산지표가 높을 수 있음.

이번 재검수에 사용한 TLR 내부 기준
- 국가별 국민정신/설정: 경제적 강점·구조적 문제·군비/식민지/개발 부담 확인
- 사회발전 8개 항목: 학문적 기반 / 연구 시설 / 농업 방식 / 보건 수준 / 행정 효율 / 산업 전문성 / 공업 장비 / 군 전문성
- 전세계 자원 5종 시작값: 철강 / 석탄 / 석유 / 식량 / 희귀광물
- 국가 기본수치: 인구 대비 가용 인력 및 국가 체급 교차확인
- 기존 법률·지도자·국민정신 효과는 시작 기본값에 중복 반영하지 않음

중복계산 방지
- 이 파일은 '국가 시작 기본값'만 기록함.
- 국민정신·지도자·법률·예산 효과는 런타임 modifier로 별도 적용함.
- 따라서 특정 국가가 '산업 강국', '연구 효율 증가', '복지 확대' 국민정신을 가지고 있더라도 그 효과 수치를 이 기본값에 다시 얹지 않음.
- 생산능력 보정은 모든 국가가 기본 100%이며, 실제 보정은 런타임 modifier에서 처리함.
- 법률 효과로 명목세율·징세효율·총지출·생산능력·연구력 등이 바뀌어도 이 파일의 기본값과 별도로 계산함.

재정 규칙
- 유동준비금: 정부가 즉시 동원 가능한 재정성 현금·단기준비자산.
- 재정수지 = 세입 - 총지출.
- 연간 부채이자 = 정부부채 × 국채금리.
- 정기 운영비는 총지출에 추가되는 비용이 아니라 총지출 안에 포함된 반복 지출의 세부내역.
- 해외영토·점령지 유지비는 비본토·비핵심 해외영토의 직접 관리비와 종속국·보호령에 대한 방위·주둔·행정보조 비용을 기록.
- 종속국 자체 국내행정비 전체를 본국에 이중계상하지 않으며, 단순 동맹 지원·외국 원조는 제외.

생산능력 규칙
- 가용 생산능력 = (기본 생산능력 × 생산능력 보정) - 국내사용 - 무역제공 + 무역수령.
- 기본 생산능력은 GDP만으로 정하지 않고 제조업 비중·산업 전문성·공업 장비·산업 인프라와 함께 조정함.
- 자원이 많아도 산업기반이 약하면 생산능력을 과도하게 높이지 않음.
- 자원이 부족한 산업국은 낮은 자원생산과 높은 수입수요로 표현하고 생산능력을 억지로 낮추지 않음.

연구역량 규칙
- 연구역량은 학문적 기반·연구 시설을 핵심 기준으로 하고, 산업기반·문해율·도시화·국가 규모를 보조 기준으로 사용함.
- 연구역량이 높은 국민정신은 이후 modifier로 적용하므로 기본 연구역량 자체를 100에 가깝게 과도하게 올리지 않음.

세금·예산 규칙
- 명목세율은 국가의 기본 조세부담을 나타내며 법률 효과 적용 전 값.
- 징세효율은 행정 발전도뿐 아니라 지방분권, 식민지 구조, 군벌화, 부패, 광대한 영토, 납세기반의 파편화를 함께 반영함.
- 예산충족도는 단순히 선진국/후진국 순위가 아니라 세수기반·행정력·부채·고정지출·군사부담을 종합해 설정함.
- 예산 5개 항목 합계 = 100%, 산업구조 6개 항목 합계 = 100%.

재검수 결과
- 62개국 전부 국민정신/설정, 사회발전, 자원, 국가 기본수치와 교차검수함.
- 연구역량·생산능력·징세효율·예산충족도·정부지출에서 체급 대비 명백한 과잉 배정은 발견되지 않음.
- 기존 v2의 숫자는 이미 상당히 보수적으로 잡혀 있어 대규모 재산정은 오히려 설정상 강점을 이중으로 약화시킬 가능성이 있다고 판단함.
- 따라서 수치 자체는 v2를 유지하고, 산정·중복계산 규칙을 명확히 확정함.
- 확정 국명에 맞춰 '컬럼비아 개척 연방' 표기를 '컬럼비아 개척연방'으로 통일함.
- 신도나우/신강/사천의 표기는 다른 기준 파일 사이에 이명 표기가 존재하므로, 이번 경제 본문에서는 기존 핵심 설정 파일의 표기를 유지함.
