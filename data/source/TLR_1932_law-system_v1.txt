TLR 1932 법률 시스템 최종 통합본 v1
================================================================
범위: 정치 8 + 군사 4 + 경제 8 + 사회 8 = 28개 법률 / 140개 선택지
용도: Codex 구현 / 운영진 검수 / 법률 시스템 기준본

통합 원본:
- TLR_1932_정치법_통합설계_확정안_v1.txt
- TLR_1932_군사법_경제법_사상조건_통합설계_v1.txt
- TLR_1932_사회법_사상조건_통합설계_v1.txt
- TLR_1932_법률효과_TNO변환_전체_v1.txt

이 파일은 각 선택지마다 다음 내용을 한곳에 합친다.
- option id
- 정치력 변경 비용
- 추가조건
- 상시 관리자 승인 여부
- 집권사상 ○ / △ / × 호환성
- TNO → TLR 변환 법률 효과
- 해당 선택지의 비고

※ 기존의 별도 법률 효과 v1은 사용하지 않는다.
※ 이 통합본의 효과 파트는 TNO 정책의 방향·대가·상대적 강도를 TLR 수치로 변환한 새 기준이다.
※ 시작 시 이미 보유한 법률은 현재 변경조건을 충족하지 못해도 자동 해제하지 않는다.
※ 조건은 '새로 해당 법률로 변경할 때'만 검사한다.

================================================================
0. 공통 변경 판정 규칙
================================================================

[집권사상]
○ 허용: 조건과 정치력을 충족하면 일반 변경 가능
△ 조건부: 조건과 정치력을 충족한 뒤 관리자 승인 필요
× 불가: 일반 UI에서 변경 불가. 집권사상 변화 또는 이벤트/디시전/관리자 강제변경으로만 처리

[판정 순서]
1. 집권 정당 대분류 사상 확인
2. ○ / △ / × 호환성 판정
3. 추가조건 검사
4. 정치력 보유량 검사
5. 상시 관리자 승인 대상 여부 확인
6. 즉시 변경 또는 승인 대기

[승인 대기]
- 승인 대기 중 현재 법률 유지
- 관리자 승인/반려로 처리
- 별도 에스크로/자동환불/승인 타이머 없음
- 반려 시 지불 정치력은 반환하지 않는 것을 기본값으로 사용

[발전도]
- 발전도는 법률 단계 해금용 테크트리가 아니다.
- 실제 제도 운영에 최소 국가역량이 필요한 경우에만 변경조건으로 사용한다.
- 강압적이거나 급진적인 법이라는 이유만으로 높은 발전도를 요구하지 않는다.

[효과 수치 해석]
- 안정도 / 전쟁 지지도 / 실업률 / 명목세율 / 명목 성장률의 '%p'는 퍼센트포인트 변화
- 생산능력 / 연구력 / 턴당 정치력 / 국가수익 / 징세효율 / 가용인력 등 '%'는 기본값 대비 수정치
- '총지출: GDP 대비 +X%'는 복지·정책으로 발생하는 GDP 비례 추가 지출
- 군사 훈련/장교 효과는 부대 편성기간·훈련도·준비도에 적용

[12개 대분류 사상]
전위사회주의 / 평의회사회주의 / 생디칼리슴 / 자유사회주의 / 사회민주주의 / 급진공화주의 / 자유주의 / 보수주의 / 권위주의 / 군주주의 / 반동주의 / 국가재생주의

부록 A. Codex 구현 규칙
================================================================

기존 LawOption의 requirements / incompatibilities를 유지하면서 아래 필드를 추가하는 방향:

politicalPowerCost: number
alwaysRequiresApproval: boolean

requirements에서 필요한 조건 유형 예시:
- rulingIdeologyCompatibility
- rulingPartySupportAtLeast
- developmentAtLeast
- atWar
- warSupportAtLeast
- stabilityAtMost
- currentLawIsNot
- directTransitionBlockedFrom

구현 원칙:
- 대분류 사상은 내부 판정용. 일반 당 UI에 대분류 사상명을 강제로 노출하지 않는다.
- 하위사상은 기본 법률 호환성 판정에 사용하지 않는다.
- ×라도 이벤트/디시전/관리자 강제변경은 가능하도록 일반 플레이어 변경 로직과 분리한다.
- modifiers는 실제 시스템에 연결되는 키만 사용한다.
- 효과를 국가 기본수치/지도자/국민정신/발전도에 중복 반영하지 않는다.
