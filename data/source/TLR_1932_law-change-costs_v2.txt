TLR 1932 법률 변경 비용·조건 확장표 v2
================================================================
범위: 정치 8 + 군사 4 + 경제 8 + 사회 8 = 28개 법률 / 140개 선택지
용도: Codex 구현 / 법률 변경 UI / hover tooltip / 운영진 밸런스 기준
기준본: TLR_1932_법률시스템_최종통합본_v1.txt

중요:
- 이 파일은 v1을 대체하거나 덮어쓰는 파일이 아니다.
- v1에 존재하는 option id / 정치력 비용 / 추가조건 / 사상 ○△× / 상시 관리자 승인 / 상시 효과는 그대로 유지한다.
- v2는 "클릭 즉시 변경"을 없애기 위해 시행기간·시행비·쿨다운·진행 상태를 추가한다.
- Codex는 기존 법률 구현을 억제하는 별도 우회 시스템을 만들지 말고, 기존 LawOption 데이터에 이 필드들을 확장해서 연결한다.

================================================================
0. 공통 변경 규칙
================================================================

[변경 가능성 판정 순서]
1. 현재 집권 정당의 대분류 사상 확인
2. v1 사상 호환성 ○ / △ / × 판정
3. v1 추가조건 판정
4. 현재 정치력 >= v1 정치력 비용인지 확인
5. 해당 선택지의 시행비를 감당할 수 있는지 확인
6. 해당 법률군의 쿨다운이 끝났는지 확인
7. 같은 법률군에서 다른 개정이 진행 중인지 확인
8. 국가 전체 동시 법률개정 한도(기본 2개)를 넘지 않았는지 확인
9. 상시 관리자 승인 또는 △ 사상 여부 확인
10. 모든 조건 충족 시 개정 시작

[사상 호환성]
○ 허용:
- 모든 조건과 비용 충족 시 개정 시작 가능.

△ 조건부:
- 모든 조건과 비용 충족 후 관리자 승인 필요.
- 승인 전에는 비용을 최종 차감하지 않는다.
- 승인 시 비용 차감 후 개정 시작.
- 반려 시 비용 차감 없음.

× 불가:
- 일반 플레이어 UI에서 개정 시작 불가.
- 이벤트 / 디시전 / 관리자 강제변경은 별도 경로로 가능.

※ 기존 v1의 "반려 시 정치력 미반환" 규칙은 폐기한다.
※ 승인 전 비용을 먼저 빼는 방식은 불필요한 분쟁을 만들므로, v2에서는 승인 시 최종 차감한다.

[시행기간]
- 단위는 턴.
- 1턴: 단순 행정조정 / 비상조치 / 규정 변경
- 2턴: 일반적인 제도 개편
- 3턴: 전국적 조직 개편 또는 중대 개혁
- 4턴: 국가구조·복지체계·소유구조 전체를 건드리는 개혁
- 시행기간 동안 기존 법률 효과가 유지된다.
- 기간 종료 시 새 법률이 적용된다.
- 개정 중에는 같은 law id의 다른 선택지로 다시 변경할 수 없다.

[시행비]
- 별도의 가상 '국고 화폐'를 새로 만들지 않는다.
- 시행비는 개정 시작 턴에 발생하는 "일회성 추가지출"이다.
- 표기값 X%는 GDP 대비 X% 상당의 추가지출을 의미한다.
- 기존 법률의 '총지출: GDP 대비 +X%'는 법률 유지 중 계속 발생하는 상시효과이며, 이 파일의 시행비와 별개다.
- 시행비 0.00%는 별도 재정비용 없음.
- 시행비가 있는 경우 tooltip에는 "일회성 시행비: GDP의 X%"로 표시한다.

[쿨다운]
- 새 법률이 실제 적용된 시점부터 계산한다.
- 쿨다운 중에는 해당 law id를 다시 바꿀 수 없다.
- 이벤트/디시전/관리자 강제변경은 쿨다운을 무시할 수 있다.
- 강제변경 후 쿨다운을 새로 걸지 여부는 호출 측에서 지정한다.

[동시 개혁]
- 기본적으로 한 국가가 동시에 진행할 수 있는 수동 법률 개정은 최대 2개.
- 관리자 승인 대기 상태는 진행 슬롯을 차지하지 않는다.
- 실제 개정이 시작되는 순간 슬롯을 사용한다.
- 이벤트/디시전/관리자 강제변경은 이 한도에서 제외한다.

[취소]
- 시행 중 개정은 플레이어가 취소할 수 있다.
- 정치력은 반환하지 않는다.
- 이미 발생한 시행비도 반환하지 않는다.
- 새 법률은 적용되지 않고 기존 법률이 유지된다.
- 취소 시 해당 law id에 1턴의 짧은 재시도 쿨다운을 적용한다.

[시작 법률]
- 게임 시작 시 이미 적용된 법률에는 시행기간/시행비/조건을 소급하지 않는다.
- 조건은 새로 그 법률로 변경하려 할 때만 검사한다.

================================================================
1. Hover Tooltip 표시 규칙
================================================================

잠긴 선택지를 포함해 모든 법률 선택지에 hover tooltip을 제공한다.

표시 순서:

법률명

해금 조건:
✓/✕ 집권사상 조건
✓/✕ v1 추가조건
✓/✕ 정치력 보유량
✓/✕ 시행비 감당 가능 여부
✓/✕ 쿨다운 종료 여부
✓/✕ 동시 개혁 슬롯
✓/✕ 관리자 승인 필요 여부 또는 승인 상태

변경 비용:
- 정치력: v1 값
- 일회성 시행비: GDP 대비 X%
- 시행기간: X턴
- 재변경 쿨다운: X턴

선택 시 효과:
- 기존 v1의 해당 option 효과를 그대로 표시

색상:
- 충족: 초록색 + ✓
- 미충족: 빨간색 + ✕
- 관리자 승인 대기/조건부: 노란색 + △

중요:
- disabled 버튼 자체에 tooltip 이벤트를 걸어 hover가 사라지지 않게 한다.
- 잠긴 버튼을 wrapper로 감싸 tooltip을 유지한다.
- 색상만으로 상태를 구분하지 않는다.

- censorship:wartime
- service:total 등 기존 전쟁조건이 있는 선택지

[총동원]
총동원은 전시 대응이므로 시행기간은 1턴으로 짧게 두되,
정치력 비용·전쟁조건·높은 시행비·기존 상시 디버프로 무게를 준다.

4. Codex 데이터 필드 권장
================================================================

기존 LawOption을 삭제하거나 새로운 병렬 법률시스템을 만들지 않는다.
현재 LawOption에 아래 필드를 추가한다.

implementationTurns: number
implementationCostGdpPct: number
changeCooldownTurns: number

국가별 진행상태 예시:

CountryLawReform
- countryId
- lawId
- fromOptionId
- targetOptionId
- status: pending_approval | implementing | completed | cancelled | rejected
- startedAtTurn
- completesAtTurn
- politicalPowerPaid
- implementationCostGdpPct
- approvedBy
- createdAt

중요:
CountryLawReform은 현재 적용 법률 그 자체가 아니다.
개정 완료 전까지 CountryLawState의 현재 option id를 바꾸지 않는다.

완료 시:
1. 기존 법률 modifiers 제거
2. target 법률 modifiers 적용
3. CountryLawState 변경
4. 쿨다운 시작
5. reform status = completed

5. Codex 보존 원칙
================================================================

- 기존 lawDefinitions.ts의 option id를 변경하지 않는다.
- 기존 modifiers를 삭제/재작성하지 않는다.
- 기존 requirements를 새로운 조건 시스템으로 덮어쓰지 않는다.
- 기존 사상 호환성을 단순한 if문 몇 개로 축소하지 않는다.
- 기존 법률 UI 전체를 새 컴포넌트로 갈아엎지 않는다.
- 기존 클릭 핸들러 위에 CSS/조건문으로 '작동 안 하는 것처럼' 억제하는 방식 금지.
- 실제 변경 호출을 CountryLawReform 생성 흐름으로 연결하고, 기존 즉시 적용 경로는 의존성 확인 후 제거한다.
- 이벤트/디시전/관리자 강제변경 경로는 수동 개정 흐름과 분리해서 유지한다.

4. 잠긴 법률도 hover 가능
5. tooltip에 기존 선택 효과 표시

8. 개정 중 같은 law id 변경 불가
9. 쿨다운 중 재변경 불가
10. 동시에 수동 개혁 3개째 시작 불가
11. 취소 시 기존 법률 유지
12. 취소 시 비용 미반환
