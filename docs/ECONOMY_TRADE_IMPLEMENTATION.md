# 경제·무역 시스템 구현 기록

## 데이터 원칙

- 국가 경제 행은 자동으로 생성하지 않는다. 값이 없는 국가는 `UNCONFIGURED`로 응답한다.
- 일부 필드만 입력된 국가는 `PARTIAL`, 필수 경제·생산 필드가 모두 입력된 국가만 `READY`다.
- `null`은 화면과 HUD에서 `미설정`으로 표시하며 `0`으로 변환하지 않는다.
- 자원 종류는 철강, 석유, 석탄, 식량, 희귀광물 다섯 개만 사용한다.

## 거래 처리

- 거래 제안은 양국이 각각 제공하는 항목을 반드시 포함한다.
- 플레이어 소유 국가는 직접 응답하고 미점유·AI 국가는 관리자 검토 큐로 전달한다.
- 수락 시 계약과 계약 항목을 트랜잭션에서 생성하며, 예정·활성 계약의 공급 약속을 합산해 초과 약속을 막는다.
- 초기 자원 무역은 반복 공급 계약으로 처리한다. 기본 재고·생산량을 정산 때마다 영구 이동시키지 않고, 활성 계약과 정산 원장에서 수입·수출 흐름을 파생 계산한다. 생산역량도 같은 방식으로 활성 계약에서만 파생해 중복 반영하지 않는다.
- 정산은 계약과 예정일로 멱등 처리하며 부족 시 `BREACHED`, 종료일 경과 시 `EXPIRED`로 전환한다.

## 운영 준비

- `tlr_run_economy_period`는 기간별 멱등 기록을 남기고, 필수 데이터가 없으면 계산값을 꾸며내지 않고 `BLOCKED_MISSING_DATA`를 기록한다.
- 준비된 국가에는 확정된 다음 예산을 적용한다. 향후 공식 경제 계산식은 `economy_rules.calculation_parameters` 한 곳에서 확장한다.
- 관리자 API는 AI 무역 검토, 계약·제한 조회, 기간 정산 실행을 제공한다.
