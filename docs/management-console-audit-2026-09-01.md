# TLR Management Console 전면 점검 기록

점검일: 2026-09-01

## 판정 기준

- `연결 완료`: 화면 조작이 관리자 인증 API와 실제 저장소를 거쳐 플레이 런타임에 반영된다.
- `관제 완료`: 실제 데이터 조회·승인·거절·조정 기능이 연결되어 있다.
- `읽기 전용`: 런타임의 실제 정의를 표시하지만 안전한 쓰기 모델이 아직 없다.
- `기반 없음`: 현재 저장 구조 또는 런타임에 해당 개념이 없어 UI만 추가하면 가짜 기능이 된다.

## 이번 재점검에서 수정한 결함

1. 한 관제 API 실패가 콘솔 전체를 빈 화면으로 만들던 일괄 로드를 도메인별 독립 로드로 변경했다.
2. 대시보드의 정적 카드와 동작 없는 버튼을 제거하고 실제 심사 대기 수와 이동 버튼으로 교체했다.
3. 이벤트 스튜디오의 정의가 플레이 화면에 전달되지 않던 단절을 해소했다.
4. 수동 예약, 세계날짜 도달, 턴 시작·종료, 조건 충족을 서버에서 판정하도록 했다.
5. 이벤트 선택 요청을 서버가 다시 검증하고, 같은 인스턴스의 재전송은 중복 처리하도록 했다.
6. 연구력 조정 API를 관리자 UI에 연결하고 국가·증감량·감사 사유를 필수로 기록하도록 했다.
7. 첩보 정의 미리보기의 동작 없는 `준비` 버튼을 상태 라벨로 교체했다.
8. 세계시간 빠른 날짜 입력을 추가하되 턴 증감과 결합하지 않았다.

## 의도적으로 가짜 구현을 만들지 않은 항목

### 공통 결정 쓰기 스튜디오

현재 결정 효과는 `COMMON_DECISIONS`뿐 아니라 서버 실행 분기와 임시 효과 분기에 함께 고정되어 있다. 화면에서 메타데이터만 저장하면 플레이 실행과 다른 가짜 결정이 되므로 이번 변경에서는 실제 런타임 카탈로그를 읽기 전용으로 유지했다. 다음 단계는 결정 정의와 실행기를 하나의 검증 가능한 효과 모델로 이전한 뒤 CRUD를 여는 것이다.

### 신규 국가 생성 및 프로빈스 소유권 재편

현재 국가 목록, 지도 색, 래스터 영토 소유권이 빌드 시 생성되는 정적 자료다. 프로빈스 그룹 저장 기능은 실제지만, 신규 국가 key를 입력하는 것만으로 지도 소유권이 바뀌지는 않는다. 동적 국가 테이블, 프로빈스 owner/controller 테이블, 지도 렌더러의 동적 조회를 먼저 도입해야 한다.

### 전체 시스템 스냅샷 복원

각 시스템 감사 로그는 존재하지만 여러 테이블을 한 시점으로 원자적으로 되돌리는 서버 트랜잭션은 없다. 단순 복원 버튼은 부분 롤백을 일으킬 수 있으므로 추가하지 않았다.
